# Landing sprites licenses

Every file in this directory is a verbatim copy (PNG) or a trimmed subset (`skin.json`) of the Agents
Office default skin in `packages/web/public/skins/default/`. That skin is original art generated
procedurally by `packages/web/scripts/generate-default-skin.mjs` (and `packages/web/scripts/skin/*`).
The PNGs are never edited here: to change the art, edit the generator, regenerate the skin and copy the
files again.
